Proposal for Simple AI

Design system that scales
with your product

A comprehensive Figma component library and design guidelines built to elevate Simple AI's voice AI product and empower your engineering team.

Project scope

Simple AI's product handles critical communication (phone calls, chats, texts) but lacks a cohesive design foundation. We're building a professional design system that gives your engineering team everything they need to ship polished, consistent interfaces.

Core deliverable

Figma component library with typography, spacing, colors, and base components

Design guidelines

Spacing rules, component documentation, and usage guidelines

Reference layouts

2–3 base layout screens to guide engineering implementation

Export options

Markdown/tokens file + Figma MCP integration for seamless Claude integration

Timeline

30-day engagement structured to unblock your engineering team quickly, then build comprehensive coverage.

Phase 1: Foundation (Days 1–10)

Core components + markdown file delivered. Your engineers can start building immediately.

Phase 2: Buildout (Days 11–30)

Full library expansion, layout screens, and Figma MCP setup.

We'll start with your existing colors and logo as a foundation, then align on direction during our kick-off:

  • Option B: Clean, minimal B2B SaaS aesthetic that projects trust and professionalism

We'll confirm your preference in week one and build the system around it.
